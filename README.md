# turing-office-assets

Persona avatars for the **Turing multi-agent "office"** — used as:
- Discord webhook avatars (per-message `avatar_url` override, one webhook per channel)
- Claw3D office sprites (#319) source
- a future photoreal-render source

256×256 PNGs, one per persona key, generated locally (SDXL on an RTX 3090).
Stable raw URLs:

```
https://raw.githubusercontent.com/Turing-Zelax25/turing-office-assets/main/avatars/<key>.png
```

Keys: turing, ada, linus, patrick, phil, grady, margaret, ross, kent, norbert, shannon, grace.
